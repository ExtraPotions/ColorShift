# ColorShift

ColorShift Anywhere provides theme palettes, accessible appearance controls and site enhancements.

**0.4.1** · [Install ColorShift Anywhere](https://github.com/ExtraPotions/ColorShift/releases/latest/download/colorshift-anywhere.user.js) · [Release notes](CHANGELOG.md)

Install with Tampermonkey or Violentmonkey, then reload a website. Update the existing script to retain settings.

- Choose themes and accents, or keep the original appearance.
- Adjust site options through a compact menu with help descriptions.
- Compatible badges align together and follow their shared anchor.
- Drag the badge to reposition it; use Escape to close the menu.
