# Diagnostics

Open **Diagnostics** from the ColorShift menu and run **Scan theme coverage** after the page settles. The visible report is ranked for quick review. **Copy diagnostics** includes the complete report, including up to 100 visual-review candidates.

Each finding includes the element type, selector or class, and the reason it was selected. Low-contrast findings are computed from rendered foreground and background colors. Visual-review candidates cover gradients, background images, unresolved surfaces, and controls that need human confirmation.

## A useful report

Include the site URL, palette, accent, enabled profile options, and the copied diagnostics text. Remove account names, private URLs, tokens, and personal content before sharing. A screenshot is optional; a selector and a short description are preferred.

Diagnostics are evidence for review, not an assertion that every candidate is wrong. Check the page visually before adding a rule.
