# Site health matrix

This is a lightweight maintenance guide, not a promise that a site will always match perfectly.

| Site/profile | Tier | Test coverage | Maintenance expectation |
| --- | --- | --- | --- |
| Generic web pages | Core / best effort | Core fixtures | Low |
| ManaPool | Profile | Focused contrast and controls tests | Medium |
| Scryfall | Profile | Coverage fixture | Medium |
| SteamGifts | Profile | Accent and coverage fixtures | Medium |
| Card Kingdom | Profile | Pricing and landing fixtures | Medium |
| Goodreads | Profile | Layout fixture | Medium |
| Genius | Profile | Layout fixture | Medium |
| TCGPlayer | Profile | Support-button fixture | Medium |

Promote a new site only after it has a stable selector set, a focused fixture, and a clear owner for future breakage.
